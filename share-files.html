Share files without an account

TextNexus sends files through the same chat room you are already talking in, so there is no second upload service to open, no expiry link to explain, and no app to install on either side.

How to send a file

  1. Open the chat. Go to TextNexus and join a room with its invite code, or create one.
  2. Attach the file. Use the attachment control in the message bar and pick a file from your device.
  3. Send. The room shows the file with its name and size, and everyone in that room can download it.
