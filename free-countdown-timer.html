Free countdown timer

Set a countdown, pause it, or leave the tab — the timer stores its end time locally, so it keeps counting while you are away. No account, no ads in the timer, no install.

How it works

The timer counts against a timestamp saved in this browser, not against a script that has to keep the page awake. Close the tab and come back: it shows the right remaining time, and says so if the countdown already finished.

When people use it

  • Timed study or work blocks, using the 25-minute preset.
  • Kitchen timers, since a phone browser is already open.
  • Meeting and classroom countdowns you want visible on a projector.
